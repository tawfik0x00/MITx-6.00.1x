# Unit 4 - Good Programming Practices

This unit focuses on writing well-structured, modular, and testable code. The seven problems incrementally build the Wordgame — a Scrabble-inspired word game — and culminate in a version where a human can compete against a computer player.

## Problems

| Directory | Problem | Key Concept |
|-----------|---------|-------------|
| [Problem_1](Problem_1/) | Word scoring with Scrabble values | Dictionary lookups, accumulator |
| [Problem_2](Problem_2/) | Update hand after playing a word | Dictionary copying, no side effects |
| [Problem_3](Problem_3/) | Validate a word against the hand and word list | Multi-condition validation |
| [Problem_4](Problem_4/) | Calculate remaining hand length | Dictionary value aggregation |
| [Problem_5](Problem_5/) | Play a single hand (human) | Interactive game loop |
| [Problem_6](Problem_6/) | Manage a multi-hand game (human only) | State persistence, command dispatch |
| [Problem_7](Problem_7/) | Human vs. computer game mode | Computer player, modular extension |
