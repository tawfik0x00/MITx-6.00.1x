# Unit 1 - Python Basics

This unit covers the foundational building blocks of Python: variables, strings, loops, and conditionals. The three problems here are string manipulation exercises that build comfort with iterating over characters and tracking state.

## Problems

| Directory | Problem | Key Concept |
|-----------|---------|-------------|
| [Problem_1](Problem_1/) | Count vowels in a string | String iteration, membership testing |
| [Problem_2](Problem_2/) | Count occurrences of "bob" | String slicing, sliding window |
| [Problem_3](Problem_3/) | Longest alphabetically ordered substring | State tracking, character comparison |
