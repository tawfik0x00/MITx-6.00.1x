# Unit 3 - Structured Types

This unit introduces Python's structured data types — strings, lists, tuples, and dictionaries — through a series of problems that build toward a complete Hangman game.

Problems 1 through 4 are scaffolded: each one implements a helper function that the next one depends on. The `hangman_game` directory contains the final assembled game.

## Problems

| Directory | Problem | Key Concept |
|-----------|---------|-------------|
| [Problem_1](Problem_1/) | Check if word is fully guessed | List membership, boolean functions |
| [Problem_2](Problem_2/) | Build the partially revealed word display | String building from a list |
| [Problem_3](Problem_3/) | Get remaining available letters | String filtering, standard library |
| [Problem_4](Problem_4/) | The full Hangman game loop | Composing functions, interactive I/O |

## Project

| Directory | Description |
|-----------|-------------|
| [hangman_game](hangman_game/) | Complete, runnable Hangman game using all helper functions |
