# Unit 2 - Simple Programs

This unit focuses on applying loops and functions to solve real numerical problems. The theme across all three problems is credit card debt repayment, with each problem introducing a more efficient computational approach.

## Problems

| Directory | Problem | Key Concept |
|-----------|---------|-------------|
| [Problem_1](Problem_1/) | Remaining balance after minimum payments | Simulation with loops |
| [Problem_2](Problem_2/) | Minimum fixed monthly payment (multiples of $10) | Exhaustive enumeration |
| [Problem_3](Problem_3/) | Minimum fixed monthly payment using bisection search | Bisection search, algorithm efficiency |

## Progression

The three problems form a deliberate progression:

1. **Problem 1** simulates a fixed scenario — pay the minimum each month and see what's left.
2. **Problem 2** searches for the answer by brute force — try every multiple of $10 until the balance clears.
3. **Problem 3** replaces the brute-force search with bisection, which finds a more precise answer (to the cent) in far fewer iterations.
