# Unit 5 - Object-Oriented Programming

This unit introduces object-oriented programming in Python through a series of problems that incrementally build a Caesar cipher system. Each problem implements one class or method, building on the previous.

## Problems

| Directory | Problem | Key Concept |
|-----------|---------|-------------|
| [Problem_1](Problem_1/) | `Message` base class — shift dictionary and apply shift | OOP, modular arithmetic |
| [Problem_2](Problem_2/) | `PlaintextMessage` subclass — encryption with a given shift | Inheritance, encapsulation |
| [Problem_3](Problem_3/) | `CiphertextMessage` subclass — brute-force decryption | Exhaustive search, word validation |
| [Problem_4](Problem_4/) | Decrypt a real story file using the cipher system | Applying the full class hierarchy |

## Project

| Directory | Description |
|-----------|-------------|
| [Cipher](Cipher/) | Complete, runnable Caesar cipher with encryption and automatic decryption |
| [Cipher_Old](Cipher_Old/) | Earlier working draft of the cipher implementation, kept for reference |
